# DEC-001 · Spec no repositório como fonte da verdade

- **Contexto:** os requisitos estavam no planejamento da AB1 (Google Doc e `.md` local), longe do código e lidos raramente. O desenvolvimento agora é em par com um agente, que precisa de uma fonte única.
- **Decisão:** `docs/spec/` é a fonte da verdade. Requisitos e regras moram só em `02-requisitos.md`. O planejamento da AB1 vira histórico. O manual (`docs/manual/`) explica e cita os IDs, nunca copia as regras.
- **Consequências:** mudança de regra começa pela spec. Se manual e spec discordarem, vale a spec.
- **Quem decidiu:** Fideles · **Data:** 10/11/2026 · **Situação:** vigente
